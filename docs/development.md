# 개발 가이드

## 구현 판단

| 주제 | 선택 | 이유 |
|---|---|---|
| 저장소 | IndexedDB (idb-keyval) | 포트폴리오 프로젝트라 서버 없이 바로 체험할 수 있게 했습니다. 이미지는 localStorage 용량을 넘기 쉽습니다. |
| 이미지 | 올릴 때 줄여서 data URL로 저장 | 객체 URL을 관리할 필요가 없고, 축소로 저장 용량과 목록 로딩 부담을 줄입니다. |
| 데이터 요청 | TanStack Query | 로딩·오류 상태와 저장 후 갱신을 한곳에서 처리합니다. 저장소가 브라우저 안에 있어 `networkMode: 'always'`로 둡니다. |
| 테마 | CSS 변수와 `data-theme` | `index.html`의 인라인 스크립트가 렌더링 전에 테마를 정해 깜빡임을 막습니다. |
| ID | `crypto.getRandomValues` | `crypto.randomUUID`는 HTTPS가 아닌 주소에서 제공되지 않습니다. |
| 린트 | oxlint | `typescript-eslint`가 TypeScript 7을 지원하지 않습니다. FSD 계층과 공개 API 규칙은 `no-restricted-imports`로 검사합니다. |
| esbuild 빌드 스크립트 | 실행하지 않음 (`pnpm-workspace.yaml`) | 없어도 빌드와 테스트가 동작합니다. 승인 여부를 정하지 않으면 `pnpm install`이 실패합니다. |
| 다른 탭 동기화 | BroadcastChannel | 화면을 나란히 띄우면 포커스 이벤트가 생기지 않아, 저장과 삭제 때 직접 알립니다. |
| 샘플 데이터 | 가상의 영화와 코드로 그린 SVG | 실제 영화 이미지의 저작권 문제를 피합니다. 지운 샘플이 다시 생기지 않도록 넣은 사실을 저장합니다. |

이미지 축소는 다음 규칙을 따릅니다.

- 크기가 기준 이내이고 300KB 이하인 파일과 SVG는 원본을 그대로 저장합니다.
- 그 밖에는 JPEG(품질 0.85)로 다시 인코딩합니다. 투명한 부분은 흰색이 되고, 움직이는 GIF는 멈춘 이미지가 됩니다.

## 테스트

| 종류 | 위치 | 검사 내용 |
|---|---|---|
| 단위·컴포넌트 | `src/**/*.test.ts(x)` | 입력 검증, 저장소, 컴포넌트와 페이지 상태, 저장·불러오기 실패 |
| E2E | `e2e/app.spec.ts` | Chromium, Firefox, WebKit에서 프로덕션 빌드의 작성·수정·삭제, 중복 제출, 이탈 확인, 탭 동기화, 이미지 축소, 테마, 키보드, 컨트롤 크기, 폭 320·1440·2200px의 넘침과 axe 검사(목록, 상세, 작성, 수정, 없는 주소) |
| 배포 검사 | `e2e/live.spec.ts` | 배포된 사이트의 목록, 직접 주소, 작성, 삭제, 샘플 되돌리기, 테마, 모바일 폭, 목록 axe 검사 (Chromium, Firefox, WebKit) |

```bash
pnpm exec playwright install chromium firefox webkit  # 처음 한 번
pnpm build
pnpm test:e2e
```

E2E는 기본으로 포트 4310을 쓰며, `E2E_PORT`로 바꿀 수 있습니다. jsdom에서는 이미지를 디코딩할 수 없어 실제 축소는 E2E에서 검사합니다.

CI는 `main` 푸시와 PR마다 타입 검사, 린트, 포맷 검사, 단위 테스트, 빌드, E2E를 실행합니다.

## 성능

배포된 사이트를 Lighthouse 13으로 측정했습니다.

| 화면 | 성능 | 접근성 | 권장사항 | SEO | LCP | TBT | CLS |
|---|---|---|---|---|---|---|---|
| 목록 (모바일) | 98 | 100 | 100 | 100 | 1.1초 | 0ms | 0 |
| 목록 (데스크톱) | 95 | 100 | 100 | 100 | 1.0초 | 0ms | 0 |
| 상세 (모바일) | 100 | 100 | 100 | 100 | 1.6초 | 0ms | 0.001 |
| 상세 (데스크톱) | 99 | 100 | 100 | 100 | 0.7초 | 0ms | 0 |

- 차단 시간이 0ms이므로 코드 분할은 넣지 않았습니다.
- 1000×1500 포스터(약 940KB) 30편을 넣은 목록도 모든 이미지가 약 90ms 안에 준비되고 JS 힙은 약 40MB여서, 목록용 작은 이미지는 만들지 않았습니다.

## 접근성

항목별 결과는 [접근성 점검](accessibility.md)을 참고하세요. axe를 통과했다고 KWCAG를 준수한다는 뜻은 아닙니다.

## 배포 시 유의점

- `main`에 병합하면 Netlify가 `netlify.toml` 설정으로 빌드해 배포합니다. 이어서 `.github/workflows/live-check.yml`이 `version.txt`로 해당 커밋의 배포를 확인한 뒤, 세 브라우저로 배포된 사이트를 검사합니다.
- 직접 주소는 SPA 대체 규칙으로 HTTP 200을 돌려줍니다. 없는 주소는 앱의 404 화면이 열리지만 HTTP 상태는 200입니다.
- 없는 `/assets/*`는 앱 화면이 아니라 404로 응답합니다. `robots.txt`처럼 고정 주소로 읽는 파일은 `public/`에 두어야 대체 규칙에 걸리지 않습니다.
- 공유 미리보기 정보는 `index.html` 하나뿐이어서 어느 주소를 공유해도 목록 기준으로 보입니다.
- 저장 데이터는 도메인별로 분리되므로, 주소가 바뀌면 이전 리뷰는 보이지 않습니다.
- `og:image`와 `og:url`은 배포 주소를 절대 경로로 씁니다. 주소가 바뀌면 `index.html`도 고칩니다.

## 알려진 제한

- 목록 카드는 2:3 틀을 유지하므로, 비율이 다른 포스터에는 배경색 여백이 생깁니다.
- 파일 선택 버튼 문구는 브라우저 언어를 따릅니다. 영어 브라우저에서는 "Choose File"로 표시됩니다.
- 같은 리뷰를 두 탭에서 동시에 수정하면 나중에 저장한 내용으로 덮어씁니다.
- 다른 탭에서 지운 리뷰를 수정 중이면, 그 탭에서도 해당 리뷰를 찾을 수 없다고 안내하며 입력 내용이 사라집니다.
